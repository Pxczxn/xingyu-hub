## 二、设计原则总结

### 1. 圆角系统
```
小元素 (Badge, 小按钮):    rounded-lg (8px)
中等元素 (Input, Button):   rounded-lg (8px)
大元素 (Card, Dialog):      rounded-2xl (16px)
特殊 (Badge):              rounded-full
```

### 2. 阴影系统
```
静态卡片:                  shadow-sm
可交互组件 (Button):       shadow-sm → hover:shadow-md
浮层 (Dialog, Dropdown):   shadow-lg / shadow-xl
```

### 3. 过渡动画
```
快速交互 (菜单项):         duration-150
标准交互 (按钮, 输入框):   duration-200
```

### 4. 间距系统
```
紧凑 (p-1):               4px   → 6px (p-1.5)
标准 (p-4):               16px  → 20px (p-5)
舒适 (p-6):               24px  (保持)
```

### 5. 字重层级
```
普通文本:                 font-normal
强调:                     font-medium → font-semibold
标题:                     font-semibold → font-bold
超级标题:                 font-extrabold
```
