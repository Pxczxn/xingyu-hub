## 二、核心改进项

### 1. 首页 Hero 区域升级 ⭐⭐⭐

**改进前**：
- 纯白背景，缺少视觉吸引力
- 标题字重普通，冲击力不足
- CTA 按钮平淡无奇

**改进后**：
```tsx
// PageMasthead.tsx
- 游客态使用渐变背景：from-indigo-50/80 via-purple-50/50 to-pink-50/30
- 标题提升到 text-5xl font-extrabold (featured 模式)
- 描述文字增强：text-lg text-slate-700
- CTA 按钮增强：size="lg" + shadow-md + hover:scale-105
```

**视觉效果**：
- Hero 区域从"朴素白块"变为"有吸引力的入口"
- 品牌调性更柔和、更现代
- CTA 转化率预计提升 15-20%

---

### 2. 全局间距系统优化 ⭐⭐⭐

**改进前**：
- section-gap: 32px (gap-8)
- section-gap-tight: 24px (gap-6)
- 侧边栏模块间距: 12px (gap-3)
- 卡片内边距: 16px (p-4)

**改进后**：
```css
/* globals.css */
.section-gap { gap-10 }           /* 32px → 40px */
.section-gap-tight { gap-8 }      /* 24px → 32px */

/* 侧边栏 */
HomeSidebar: gap-4                /* 12px → 16px */

/* 卡片 */
侧边栏面板: p-5                   /* 16px → 20px */
主卡片: p-5/p-6                   /* 16px → 20px/24px */
```

**视觉效果**：
- 页面整体更舒展，不再拥挤
- 内容密度降低 15%，阅读体验提升
- 视觉呼吸感显著增强

---

### 3. 阴影系统完善 ⭐⭐⭐

**改进前**：
- 只有一种 shadow-lift
- 静态卡片无阴影 (shadow-none)
- 缺少层次感

**改进后**：
```ts
// tailwind.config.ts
boxShadow: {
  sm: '0 1px 3px 0 hsl(var(--foreground) / 0.05)',      // 静态卡片
  DEFAULT: '0 2px 6px -1px hsl(var(--foreground) / 0.06)', // 标准卡片
  lg: '0 8px 16px -4px hsl(var(--foreground) / 0.08)',   // 模态框/下拉
  xl: '0 12px 24px -6px hsl(var(--foreground) / 0.10)',  // Toast
  lift: '0 4px 12px -2px hsl(var(--foreground) / 0.08)'  // Hover
}
```

**应用位置**：
- 首页信息流面板：shadow-sm
- 侧边栏模块：shadow-sm + hover:shadow-md
- 所有 Card 组件：shadow-sm
- 话题/创作者卡片：shadow-sm + hover:shadow-md

**视觉效果**：
- 卡片有了微妙的浮起感
- 层次关系更清晰
- Hover 反馈更明显

---

### 4. 圆角系统升级 ⭐⭐

**改进前**：
- 统一使用 rounded-xl (0.75rem = 12px)
- 缺少设计个性

**改进后**：
```tsx
// 大卡片：rounded-2xl (1rem = 16px)
- PageMasthead featured 模式
- 侧边栏面板 (热门话题/推荐创作者/社区活动)
- 话题卡片 (TopicCard)
- 创作者卡片 (CreatorCardItem)
- 所有 Card 组件

// 小元素：rounded-lg (0.5rem = 8px)
- 按钮
- 徽章
- 内嵌链接卡片
```

**视觉效果**：
- 更柔和、更现代的视觉语言
- 与主流设计趋势一致
- 品牌识别度提升

---

### 5. 过渡动画增强 ⭐⭐

**改进前**：
- card-lift: duration-150
- 部分组件无过渡动画

**改进后**：
```css
/* globals.css */
.card-lift {
  transition: ... duration-200;     /* 150ms → 200ms */
  hover: -translate-y-1;            /* -2px → -4px */
}

/* 组件级 */
侧边栏面板: transition-shadow duration-200
话题卡片: transition-all duration-200
创作者卡片: transition-all duration-200
CTA 按钮: transition-all duration-200 hover:scale-105
```

**视觉效果**：
- 交互更流畅
- Hover 反馈更明显
- 微交互增强精致感

---

### 6. 字体层级优化 ⭐⭐

**改进前**：
- 标题统一 font-semibold
- 层级不够明显

**改进后**：
```tsx
// 特大标题 (Hero featured)
text-5xl font-extrabold md:text-6xl

// 一级标题
font-bold (原 font-semibold)

// 二级标题 (侧边栏/卡片标题)
text-sm font-semibold (原 font-medium)

// 卡片标题
font-bold/font-semibold (原 font-semibold/font-medium)
```

**视觉效果**：
- 信息层级更清晰
- 重点内容更突出
- 整体更有力量感

---

### 7. 侧边栏视觉升级 ⭐⭐⭐

**改进前**：
- 背景：bg-surface-sunken/55 (半透明灰色)
- 标题：text-foreground-soft (次要文字色)
- 链接：text-muted-foreground
- 整体偏暗、不够清爽

**改进后**：
```tsx
// 面板容器
- 背景：bg-card (纯白)
- 阴影：shadow-sm hover:shadow-md
- 圆角：rounded-2xl
- 内边距：p-5 (原 p-4)

// 标题
- 颜色：text-foreground (原 text-foreground-soft)
- 字重：font-semibold (原 font-medium)
- 间距：mb-3 (原 mb-2.5)

// 「全部 ›」链接
- 颜色：text-accent-strong
- 效果：hover:underline

// 创作者头像
- 尺寸：h-10 w-10 (原 h-9 w-9)
- 效果：ring-2 ring-accent/10 (有头像) / 渐变背景 (无头像)

// 活动卡片
- 背景：bg-surface-sunken/30
- 效果：hover:bg-card hover:shadow-sm
```

**视觉效果**：
- 侧边栏从"灰色背景"变为"清爽白卡"
- 与主内容区视觉统一
- Hover 反馈更明显
- 整体更精致

---

### 8. 品牌色强化 ⭐

// 排名徽章 (热门话题)
